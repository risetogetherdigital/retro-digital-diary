LITTLE INTERNET DIARY — NEOCITIES PROJECT

Files:
- index.html: page content
- style.css: colors, layout, responsive design
- script.js: interactive diary notes, treasure tiles, guestbook demo

HOW TO UPLOAD TO NEOCITIES
1. Sign in to Neocities and open your site dashboard.
2. Open the file manager.
3. Upload index.html, style.css, and script.js to your site's root folder.
4. If asked to replace index.html, back up your old website first.
5. Open https://YOUR-SITE.neocities.org/ to check the result.

IMPORTANT
- This is a static frontend project. It does not need a backend.
- The guestbook only shows notes in the current page session. It does not store them online.
- The font uses Google Fonts when internet access is available; fallback fonts are included.
- Replace the sample diary dates/text with your own content.
